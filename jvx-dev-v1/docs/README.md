## 📞 Suporte

Se não encontrar o que procura na documentação:

1. Verifique a seção "Solução de Problemas" no [GUIA-COMPLETO.md](GUIA-COMPLETO.md)
2. Execute o diagnóstico: `bin/diagnostico.bat`
3. Consulte os logs do servidor
4. Abra uma issue no repositório
