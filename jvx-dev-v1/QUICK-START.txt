┌───────────────────────────────────────────────────────────────────────────┐
│ PASSO 1: PRÉ-REQUISITOS                                                   │
└───────────────────────────────────────────────────────────────────────────┘

  ✓ Node.js (v16+)        → https://nodejs.org/
  ✓ XAMPP                 → https://www.apachefriends.org/
  ✓ MySQL rodando         → Abra XAMPP, clique "Start" no MySQL

┌───────────────────────────────────────────────────────────────────────────┐
│ PASSO 2: CRIAR BANCO DE DADOS                                             │
└───────────────────────────────────────────────────────────────────────────┘

  1. Acesse: http://localhost/phpmyadmin
  2. Clique em "Novo"
  3. Nome: worksdb
  4. Clique em "Criar"
  5. Selecione "worksdb"
  6. Aba "SQL"
  7. Cole conteúdo de: database/database-init-clean.sql
  8. Clique "Executar"

┌───────────────────────────────────────────────────────────────────────────┐
│ PASSO 3: INICIAR SISTEMA                                                  │
└───────────────────────────────────────────────────────────────────────────┘

  🖱️  Duplo clique em: iniciar-projeto.bat

  Aguarde as 2 janelas abrirem:
    → Backend (porta 3001)
    → Frontend (porta 5173)

┌───────────────────────────────────────────────────────────────────────────┐
│ COMANDOS ÚTEIS                                                            │
└───────────────────────────────────────────────────────────────────────────┘

  npm run server      → Apenas backend
  npm run dev         → Apenas frontend
  npm start           → Backend + Frontend
  npm run test-db     → Testar conexão
  npm run populate    → Popular com dados

┌───────────────────────────────────────────────────────────────────────────┐
│ PARAR SISTEMA                                                             │
└───────────────────────────────────────────────────────────────────────────┘

  Ou feche as janelas do servidor

┌───────────────────────────────────────────────────────────────────────────┐
│ PROBLEMAS?                                                                │
└───────────────────────────────────────────────────────────────────────────┘

  ❌ MySQL não conecta?
     → Verifique se XAMPP está aberto
     → Verifique se MySQL está verde
     → Verifique se banco "worksdb" existe

  ❌ Porta já em uso?
     → Execute: parar-projeto.bat

  ❌ Erro ao instalar?
     → Delete: node_modules e package-lock.json
     → Execute: npm install
